# 定时任务安全与降耗规范（Official Cron Plugin）

创建或修改任何 OpenClaw 定时任务时，必须严格遵守以下 4 条底线：

1. **强制隔离会话（禁止污染主对话）**：
   - 定时任务一律默认使用 `sessionTarget: "isolated"` + `lightContext: true`。
   - **严禁**把定时任务挂载到长期主对话（如 `session:agent:main:portal-main-bear`），否则会把高额历史上下文带入每次定时执行，并持续撑爆主对话。
2. **强制明确时区**：
   - 所有 `cron` 表达式必须显式设置 `tz: "Asia/Shanghai"`，避免 UTC 偏移导致半夜误触发。
3. **禁止高频空烧**：
   - 严禁创建间隔小于 1 小时的常驻 LLM 巡检任务；若确需监控变化，必须先由本地 Python 脚本做零 Token 差量判断，无变化直接退出。
4. **脚本优先，输出极简**：
   - 同步数据（如今日焦点、汇总报表）先由 `tools/*.py` 确定性处理并落盘，模型只做 1 屏以内的精炼总结，不复述原始 JSON。
